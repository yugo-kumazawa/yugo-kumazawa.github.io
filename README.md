# Graphics Lab

グラフィックを試作しながら確かめるための、小さなブラウザツール置き場です。
GitHub Pages で公開する静的サイトで、ビルド工程はありません。

処理はすべてブラウザ内で完結します。読み込んだファイルがどこかへ送られることはありません。

## 収録ツール

### Ripple — SVG 波紋ジェネレーター（`/ripple/`）

任意の SVG を読み込み、倍率を変えながら重ねて波紋状のグラフィックをつくります。
図形は複数読み込めて、内側から順に繰り返し使われます。

| | できること |
| --- | --- |
| 図形 | 複数の SVG を読み込み、内側から順に**循環**させて重ねる。並べ替えと大きさ揃え |
| 複製 | 段数、開始／終了倍率、**等差／等比**の分布切り替え、段ごとの回転とランダム化 |
| 原点 | 拡大の中心。9 点プリセット、数値入力、プレビュー上のドラッグ |
| 塗り | 塗り／線／両方／元の色。複数色を**補間**または**循環**で割り当て |
| 配色 | OKLab（既定）または sRGB での補間、段ごとの不透明度、ドラッグで並べ替え |
| フレーム | 縦横比とズームを決めて、はみ出した外側の段を切り落とす（クリッピングマスク） |
| 書き出し | SVG、PNG（倍率指定、透明背景対応） |

数値を扱う項目はすべて、スライダーと数値入力の両方から操作できます。
値を持つのは数値側なので、スライダーの範囲を超えた値を入れても保たれます。

#### 等差と等比

両端（開始倍率・終了倍率）を固定したまま、間の配り方だけを変えます。
到達点が揃うので、分布そのものの違いがそのまま見た目の違いになります。

- **等差** — 段の差が一定。等間隔の同心状になる。
- **等比** — 段の比が一定。中心が詰まり、外へ行くほど間隔が広がる。

#### 複数の図形を重ねる

読み込んだ図形は一覧に並び、内側の段から順に繰り返し使われます。
2 つなら 1 段おき、3 つなら 2 段おきに同じ図形が現れます。
色の割り当ては図形とは独立なので、図形 2 種 × 色 3 色なら 6 段で
一巡する模様になります。

SVG ごとに viewBox の寸法はまちまちで、そのまま重ねると図形の大小が
ばらついてしまいます。既定では、2 つ目以降を 1 つ目の箱の中央へ
縦横比を保ったまま収めてから重ねます（「大きさを揃えてから重ねる」）。
元の寸法比のまま重ねたい場合は外してください。

倍率の系列と原点は、常に 1 つ目の図形の箱を基準にします。

#### 角度のランダム化

段ごとの回転に、指定した範囲の角度を上乗せします。範囲は最小・最大を
数値で指定します。

乱数には**種**を持たせてあります。`Math.random` のままだと、段数や色を
いじるたびに角度が振り直されてしまい、気に入った崩れ方を保ったまま
他を詰める、という作業ができないためです。種が同じなら結果も同じで、
「振り直す」で別の種に移ります。

#### 描画順

塗りつぶしの図形では「大きい順」でないと内側の段が隠れます。
線だけで描く場合はどちらでも成立します。

#### クリッピングマスク

フレームからはみ出した段は、画面上は viewBox の外なので見えません。
ただしそれは表示されていないだけで、図形自体は枠の外へ伸びたままです。
Illustrator などで開くとアートボードの外にはみ出して残ります。

「はみ出しをクリッピングマスクで切り取る」を入れると、フレームと同じ
矩形の `<clipPath>` が出力に含まれ、実体として切り取られた状態になります。
Illustrator ではクリッピングマスクとして開きます。
外すと、後で編集できるよう図形は伸びたまま書き出されます。

#### 読み込む SVG について

- `viewBox` があるものが最も安定します。無い場合は `width` / `height`、
  それも無ければ実際に描画して外接矩形を測ります。
- 「元の色」以外のモードでは、元の SVG の `fill` / `stroke` 指定を外してから
  段ごとの色を流し込みます。Illustrator 書き出しのような `<style>` の
  クラス指定にも対応しています。
- 安全のため、読み込み時に `<script>` やイベント属性は取り除かれます。
- グラデーションや `clipPath` の ID は自動で付け替えるため、
  出力側の ID とぶつかりません。

#### 出力の構造

素は `<defs>` の中に図形ごとに 1 つずつ置き、各段は `<use>` で参照します。
段数を増やしても `<defs>` の中身は増えないので出力は軽く、書き出した SVG を
後から編集するときも 1 か所直せば同じ図形の全段に効きます。

`<use>` には `href` と `xlink:href` の両方を書きます。SVG 1.1 しか
解さない読み手（Illustrator など）は後者しか見ないため、片方だけだと
そうしたアプリで中身が空のまま開いてしまいます。

```svg
<svg viewBox="…" width="…" height="…">
  <rect …/>                        <!-- 背景（透明指定時は無し） -->
  <defs>
    <g id="ripple-unit-0">…</g>    <!-- 1 つ目の図形 -->
    <g id="ripple-unit-1" transform="…">…</g>   <!-- 2 つ目。transform は大きさ揃え -->
  </defs>
  <g id="ripple-copies">
    <use href="#ripple-unit-0" xlink:href="#ripple-unit-0" transform="…" fill="…"/>
    …
  </g>
</svg>
```

## 開発

ビルドもパッケージも不要です。ES モジュールを使っているため、
`file://` で直接開かず、簡易サーバー経由で表示してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ripple/
```

## 単一ファイル版

`ripple/` の中身を 1 枚の HTML にまとめられます。配布したり、
サーバーを立てずに開いたりする場合に使います。

```sh
node tools/build-standalone.mjs
#   dist/ripple.html          単体で開ける HTML（file:// でも動作）
#   dist/ripple-fragment.html 外側の枠を持たない断片（埋め込み用）
```

サンプル図形は埋め込まれるため、取得のための通信は発生しません。
保存は、埋め込み先が保存用の窓口を持っていればそちらへ渡し、
無ければ通常のダウンロードになります。

## 構成

```
index.html            ツール一覧
assets/css/           共通のトークンとリセット
ripple/
  index.html          ツール本体
  css/app.css
  js/
    main.js           画面の配線、プレビュー、書き出しの呼び出し
    svg-source.js     読み込み・無害化・ID 付け替え・寸法の確定
    series.js         倍率の系列（等差／等比）
    color.js          色の解析と OKLab 補間
    compose.js        出力 SVG の組み立て
    exporter.js       SVG / PNG の保存
  samples/            サンプル図形
tools/
  build-standalone.mjs  単一ファイル版の生成
```
